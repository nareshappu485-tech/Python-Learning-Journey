# Student Marks Analysis using Python

## Project Overview
This is my first Python project. It analyzes student marks and displays their academic performance.

## Features
- Displays student names and marks
- Calculates total and average marks
- Finds highest and lowest marks
- Identifies Pass or Fail status

## Technologies Used
- Python
- Dictionary
- Loops
- Conditional Statements
- Built-in Functions

## How to Run
```bash
python student_marks.py
```
